# コーネルノートの王道

コーネル式ノート術（キュー・ノート・まとめの3分割）で記録できる、ブラウザだけで動くノートアプリです。

## 使い方

1. `コーネルノートを開く.exe`（ノートのアイコン）をダブルクリックして開く（インストール不要）
   - `.exe`はただの起動ショートカットで、中身は`コーネルノート.html`をブラウザで開いているだけ
   - 直接`コーネルノート.html`をダブルクリックしても同じように使える
   - 初回起動時にSmartScreenの警告が出た場合は「詳細情報」→「実行」で開ける（未署名の個人配布ファイルのため）
2. 「＋ 新規ノート」でノートを作成
3. 左：キュー（キーワード・疑問点）／右：ノート（授業・講義の内容）／下：まとめ、を記入
4. 入力内容は自動保存されます

## ファイル構成

- `コーネルノートを開く.exe` : アイコン付きの起動ファイル（`コーネルノート.html`を同じフォルダ内から探して開くだけ。フォルダを丸ごと移動・展開しても動作する）
- `コーネルノート.html` : アプリ本体
- `icon.ico` / `desktop.ini` : フォルダ表示用アイコン設定（コピーの仕方によっては反映されないことがあります）

## データについて

- ノートはこのブラウザ内（localStorage）にのみ保存されます。他の人には共有されません。
- 別のパソコン・ブラウザに移したい場合は、左上の「書き出し」でMarkdown（.md）ファイルとして保存し、移動先で「読み込み」してください。
- 書き出したMarkdownファイルは見出し付きの読みやすい文章形式なので、そのままAI（Claude Codeなど）に読ませて内容を要約・質問することもできます。
- 以前のバージョンで書き出したJSONファイルも、そのまま「読み込み」で読み込めます。
- ブラウザのキャッシュ・閲覧履歴を削除すると、書き出していないノートは失われます。定期的な「書き出し」をおすすめします。

## 印刷・PDF保存

ノート右上の「印刷 / PDF保存」から、そのノート1枚を印刷またはPDF保存できます。

## 動作環境

Chrome / Edge / Firefox などの一般的なブラウザで動作します。特別な設定やインターネット接続は不要です。
